## Decisions and deviations

- **server-ia outage (2026-10-28 12:37–12:48 UTC):** SSH banner timeouts. JEV (`wait_then_local`, 0.94): wait up to 90 minutes, then run the same frozen code on the PC CPU. The server came back after 11 minutes; nothing ran locally.

- **Policy (2026-10-28):** age, sex and kinship words are kept, as NAVAJO's EGP v2 design document states ("67 años → CLINICAL:AGE → Keep"; the model needs them for dosing). MEDDOCAN counts them as PHI, so all-PHI metrics penalise NAVAJO for this choice. The pre-registered direct-identifier subset does not include them.
- **Presidio control (2026-10-28):** the code enables Presidio's language-agnostic recognizers for `es` if they are missing. In E007, presidio-analyzer 2.2.364 already loaded all of them for Spanish by default (`presidio_added_for_es: []`), so the control is Presidio's default Spanish configuration: CreditCard, Crypto, Date, Email, EsNie, EsNif, Iban, Ip, MacAddress, MedicalLicense, Phone, Spacy (es_core_news_lg) and Url recognizers.
- **E008 on the PC (2026-10-28):** `cola auditoria` frees the lane and `cola.py` has no transition back to EN CURSO, so a new server job would wait forever. E008 is a few minutes of CPU; it runs on the PC with the same pinned versions (spaCy 3.8.16, Presidio 2.2.364, es_core_news_lg 3.8.0). Parity is checked first by re-running Presidio on the original test split and comparing with E007.
- Local runs use 100–200 bootstrap resamples to save time; the reported runs on server-ia use 2,000.
- spaCy-based systems (S2, N3, H4) and Presidio need packages that are not installed on the PC; they run only on server-ia (E007).
